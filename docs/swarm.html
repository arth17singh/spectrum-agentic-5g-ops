Swarm Tower

The Swarm Tower is where the trained network model goes to work. It shows a simulated city network (the "twin"), the 46 AI agents that look after it, every message they send each other, and every action they try to take. Agents can only touch the network through a policy gateway, and big changes wait for a human. This is the screen for the incident (a fibre cut during a stadium let-out) and for the prompt-injection attack.

What this screen is for

Mission Control tells you that something is happening. The Swarm Tower shows you how the system handles it. Everything on this page answers one question a judge will have about AI agents running a real network: "What stops them from doing something stupid or dangerous?"

The one-sentence story: a fibre is cut while 68,000 people leave a stadium, the agents detect it, reroute traffic, argue about the fix, test the fix on a copy of the network, and then ask a human because the fix is too big to make alone. Later, an attacker hides an instruction in a log line, one agent is fooled, and the guard rails catch it.

Where it sits in the lifecycle: the model trained in Learn, checked in Verify and rolled out in Release is the model the 40 site agents are assigned here (in mock mode their model calls are simulated). Every message and action on this page is written to the signed ledger you see in Prove.

Real or simulated, in one paragraph

No language model is actually called in mock mode. Agent "thinking" is a random delay and a modelled token count, the negotiation text and the plan are scripted, and the network KPIs come from a small simulator. What is real: each agent-to-agent message is signed with that agent's own Ed25519 key (a digital signature that proves who wrote a message), the authority check and the prompt-attack filter run on it, every action goes through a deterministic policy evaluator that mirrors the Cedar policies (rules written in AWS's Cedar policy language) shown in the Trust Center, a quarantine really revokes the agent's key, and every message, action and decision lands in the real hash-chained ledger (each record includes the fingerprint of the one before, so any edit shows).

How an agent action reaches the network

No agent touches the twin directly. Every tool call (reroute, wake a cell, change power, rebalance load, even a KPI read) goes through one function on the server, Swarm.gateway() in engines/swarm.py. This is the most important mechanism on the page.

  1. Agent askstool, parameters, target, context (blast radius, plan id, human approved?)
  2. Kill switchif frozen: deny everything except get_kpis and simulate_change
  3. Policy evaluatorTrust.authorize(): permit, needs human, or deny
  4. Ledgertool.call record, signed with the agent's key
  5. Twin applies itonly on permit; KPIs recompute

The evaluator first looks for any "forbid" rule that matches; any match is a deny. Then it looks for a "permit" rule. If a radio change is permitted but has not been approved by a human, it checks the size: more than 5% of cells means "needs human". So does an agent class at autonomy L2 or lower. If nothing permits the call, the answer is deny by default.

Deeper detail for curious judges

For each site the simulator works out demand (a base level, a slow wave that repeats about every 1.5 hours, plus any surge or absorbed load, minus any load handed off) and capacity (number of awake cells, any power boost, times 2% if backhaul is down or 90% on microwave). Load (PRB) is demand divided by capacity (with 15% headroom), capped at 100%. Users is demand times 1,400. Dropped calls rise once load passes 82%, plus a flat 6% if backhaul is down. Power is 3.1 kW per awake cell and 0.35 kW per sleeping cell, plus a little for boosts.

That is why the numbers move the way they do: at 3 s the H3 sites have almost no capacity, so health falls to 67.5%; at 3.8 s the reroute restores 90% capacity, so health recovers to 80% but the stadium is still overloaded; after the plan runs, three extra cells and load sharing bring congestion to 55%, and power rises because three cells woke up.
